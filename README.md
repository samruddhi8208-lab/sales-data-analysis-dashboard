# Sales Data Analysis & Dashboard

## Project Overview

This project analyzes sales data using Python and Power BI.

The project includes data cleaning, data transformation,
exploratory data analysis (EDA), data visualization, and
interactive dashboard creation.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Power BI

## Project Workflow

Sales Dataset
↓
Data Cleaning
↓
Data Transformation
↓
Exploratory Data Analysis
↓
Data Visualization
↓
Power BI Dashboard
↓
Business Insights

## Data Cleaning

- Checked missing values
- Checked duplicate records
- Converted Order_Date into datetime format
- Created Month and Month_Name columns
- Calculated Profit Margin

## Exploratory Data Analysis

The analysis includes:

- Total Sales
- Total Profit
- Total Quantity
- Category-wise Sales
- City-wise Sales
- Product-wise Sales
- Monthly Sales Trend
- Category-wise Profit

## Dashboard

An interactive Power BI dashboard was created
to analyze sales performance by city, category,
and product.

## Project Files

- `data/sales.csv` – Original sales dataset
- `output/cleaned_sales.csv` – Cleaned dataset
- `charts/` – Generated visualizations
- `analysis.py` – Python analysis code
